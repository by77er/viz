# Tasks a first-time on-call person does on these views

The person: on call, woken at night, opening the "Services overview" dashboard (or Explore) for the first time, at a desk (1440 px, mouse and keyboard) or on a phone (400 px, touch).

1. Change the time range to the last 6 hours.
2. Type an exact range (from 18 Nov 09:00 to 18 Nov 10:00).
3. Read the exact value of one series at a given time (checkout's error rate at 09:45).
4. Find which service has had the most errors over the range.
5. Open one panel's query in Explore.
6. Read what a panel is for (its description).
7. Switch a variable (on "Service: rate, errors, duration": Status from 500 to 200).
8. Read the dashboard as text.
9. Move the range one step earlier.

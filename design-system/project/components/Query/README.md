A query or code shown or edited in place. `vz-query`: `code` type on `sunken`.

With a coarse pointer the well is `control-touch` tall with `body`-size text, like any text input, and an editor placed inside it inherits that size.

It scrolls sideways instead of wrapping, because line breaks change how a query reads. The editor marks errors with a `status-critical` underline; it does not colour tokens by type.

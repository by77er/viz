Facts about one thing, as names and values. A `dl` with class `vz-kv`: each `dt` in `ink-secondary`, each `dd` in `ink`; numbers and identifiers in the `dd` take `vz-num`.

- Use it for a handful of unlike facts about a single thing (a rule's settings, a report's cost). Comparable things in rows are a table; a single figure that is the point is a `vz-stat`.
- The name column is as wide as its longest name, up to 40% of the list; values wrap, names do not.
- Names are nouns in sentence case with no colon. A value that is absent says so in words ("nothing", "never"); it is not left blank and not a dash.
- No rules between rows: the list is short, and distance does the grouping.

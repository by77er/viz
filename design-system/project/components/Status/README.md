The state of one thing: an 8px square in a status colour, then a word in `ink`. `vz-status` with `data-state` of `ok`, `warn`, `critical` or `info`; no state means unknown.

The word is required and is never coloured. Critical is also weight 600, so state survives without colour. Use the word that says what is wrong ("Burning budget"), not the level ("Critical").

A choice among two to six options that changes the view in place, such as a time range or a chart, table and text toggle. Buttons inside `vz-segmented`, the chosen one with `aria-pressed="true"`.

The chosen segment is `ink` in `ui-strong` on `rule`. It is marked, not inverted and not blue, so it never draws the eye before the primary action. For more than six options use a `vz-select`.

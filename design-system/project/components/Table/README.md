Rows of comparable things. `vz-table` with `vz-label` column heads on `sunken`.

- The identifying column is first, at weight 600 (`data-key`).
- Numbers are `vz-num vz-right`: monospace, tabular, right-aligned, with the unit in the head or after the value.
- Rows are `row` tall and separated by `rule`. No zebra striping, no vertical rules.
- State is a `vz-status`, never a coloured cell.

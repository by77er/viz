One number that is the answer to a question. `vz-stat` with a `vz-label`, the value in `display` size and a line of context.

Use it only when a single figure is the point. The context line is required and starts with the window or the age the number covers ("last 5 min", "30-day window"), then what it is measured against. Figures shown together on one screen must agree with each other and with the table or chart beside them. If state matters, add a `vz-status` in the context line; the number itself stays `ink`.

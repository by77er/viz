The product's sections, across the top. `vz-nav`: the name, then links; the current one has `aria-current="page"` and is `ink` in `ui-strong`.

It scrolls sideways on narrow screens instead of collapsing into a menu, so every section stays one tap away. In running text, links are `vz-link`: `ink` with an underline that thickens on hover. Links are never blue.
